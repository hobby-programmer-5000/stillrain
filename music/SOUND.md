# SOUND — 머문 비의 모든 소리 (`music/synth.js`, `tools/listen.mjs`)

소리 파일은 하나도 없다. 모든 소리는 Web Audio로 그 자리에서 만든다. 잡음 버퍼도 이름 붙은 시드로 만들어서(`Math.random` 없음) 몇 번을 돌려도 같은 소리가 난다.
그림이 읽는 표를 소리도 그대로 읽는다. 그래서 그림과 소리가 어긋날 수 없다.

## 어떻게 움직이나

재생할 때 즉흥으로 정하는 소리는 없다. 큐 시트(어느 필름 시각에 어느 악기가 어떤 인자로 울리는지)와 레인(바람, 비, 음악 크기 같은 느린 제어 곡선)을
공유 표에서 한 번 계산해 두고, 스케줄러가 필름 시각을 AudioContext 시각으로 바꿔 미리 예약한다. 그래서 실시간 재생, 탐색, 오프라인 렌더가 모두 같은 시각에 같은 소리를 낸다.

- 울림(`FILM.events.T`)마다 그 소리가 정확히 울림 시각에 시작한다(`check()`로 1 ms 안인지 확인).
- 방울이 놓이는 '똑'(플링크)은 그림과 같은 공식(`tr = t0 + 거리 / 30 m/s + 끄는 시간 + 0.08 씨앗`)으로 시각을 정한다. 그림에서 방울이 놓이는 바로 그 순간에 들린다.
- 비 소리 크기는 그 공식으로 샷의 피사체(귀) 근처에 지금 얼마나 비가 떨어지는지 세어서 정한다.

`synth.js`는 여덟 부분이다.

| 부분 | 하는 일 |
|---|---|
| 1. 엔벨로프 | 꺾은선 곡선을 AudioParam에 쓴다. 탐색 뒤 소리 중간부터 들어가도 그 자리 값에서 시작한다 |
| 2. 버퍼 | `DSPKIT`가 씨앗 잡음으로 긴 버퍼(잡음, 빗소리, 반짝임, 잔향 임펄스, 칼림바)를 만든다. 필름이 로드되는 동안 워커에서 |
| 3. 데스크 | AudioContext 하나에 믹스 그래프: 침대, 버스, 잔향, 메아리, 컴프, 리미터, 부드러운 클립 |
| 4. 악기 | `INST[k]` 44개. 음 하나에 필요한 오실레이터·필터·엔벨로프를 짓는다 |
| 5. 들판 분석 | 방울 전부를 한 번 훑어 귀 근처 비의 양(10 Hz 곡선)과 울림별로 귀 가까이에서 놓이는 방울을 모은다 |
| 6. 큐 시트 | 마디 순서대로 쓴 모든 소리 + 들판의 플링크 + 다른 모듈의 발신원, 시각순 정렬 |
| 7. 레인 | 바람, 돌풍, 비 세 줄, 음악·세상 크기, 잔향, 메아리, 마스터의 시간 곡선 |
| 8. 스케줄러 | 필름 시각 ↔ 컨텍스트 시각, 25 ms 타이머로 약 180 ms 앞까지 예약(탭이 숨으면 2.5초). 공개 API와 오프라인 렌더 |

## API (`FILM.music`)

| 호출 | 설명 |
|---|---|
| `start()` | 사용자 동작(클릭, 키) 안에서 AudioContext(48 kHz)를 만들거나 다시 켜고, 지금 필름 시각부터 재생한다 |
| `pause(bool)` | 멈춤 / 다시 재생(컨텍스트 suspend / resume). 멈춘 동안 `clock()`은 `null` |
| `seek(t)` | 예약한 소리를 모두 거두고(40 ms 페이드) t부터 다시 예약한다. 이미 울리고 있어야 할 긴 소리는 중간부터 들어온다 |
| `clock()` | 재생 중이면 오디오 시계로 본 필름 시각(출력 지연을 뺀 값), 아니면 `null`. main.js는 이 시계를 따라 그림을 그린다 |
| `mute()` | 소리 끔/켬을 바꾸고, 지금 꺼져 있으면 `true` |
| `offline(sr, from, dur, opts?)` | 같은 악보를 OfflineAudioContext로 렌더해서 `Promise<AudioBuffer>`. 녹화(`?rec=`, `tools/record.py`)와 `tools/listen.mjs`가 쓴다. `opts.only`: `'beds'` `'mus'` `'sfx'` 한 줄기만, `opts.kinds`: `['voice','choir']` 그 악기만 |
| `add(group, cues)` | 다른 모듈의 작은 발신원. `[{ t, k, a, d }]`(시각, 악기, 인자, 길이). 같은 이름의 기본 묶음(`chimewings` `frogs` `laughs` `stomps` `tock` `pellsteps`)을 대신하고, 다른 이름이면 그냥 더한다. `start()` 전에 부른다 |
| `check()` | 울림마다 그 시각(1 ms 안)에 시작하는 소리가 있는지: `{ ok, miss, off, tolls }`. `tools/listen.mjs`가 출력한다 |
| `rainAt(t)` | 귀 근처에서 지금 떨어지는 비의 양, 띠별 `[무거운, 구슬, 안개]` 0..1(샷별 다듬기 전 값) |
| `CUES` `lanes` | 큐 시트 `[{ t, k, a, d, tolls }]`와 제어 곡선(바람, 돌풍, 비 세 줄, 음악, 세상, 잔향, 메아리, 마스터) |
| `voice` | `'formant'`(기본) 또는 `'ocarina'`(대체 음색). 주소에 `?voice=ocarina`로도 바꾼다 |
| `state` `stats` `INST` | 상태, 측정값(`prepMs` 분석, `workerBuffers` 워커가 만든 버퍼 수, `startParts` 시작 시간 내역, `cues`, `plinks`, `field` 방울 출처, `releaseMismatch` 비 모듈과 울림 표의 어긋남 수 등), 악기 함수들 |

준비: 필름이 다 로드되면(`FILM.ready`) 48 kHz 버퍼를 워커(인라인 Blob)에서 만들고, 분석·큐 시트·레인 계산 한 번(측정 약 0.15–0.4초)은 쉬는 틈(`requestIdleCallback`)에 한다. 그래서 `start()`는 그래프만 짓는다(측정 약 60 ms).
워커를 못 쓰거나 6초 안에 다 오지 않으면 남은 버퍼를 쉬는 틈마다 하나씩 메인 스레드에서 만든다. 그 전에 누르면 남은 것을 그 자리에서 마저 만든다. 같은 코드와 같은 씨앗이라 어디서 만들어도 샘플이 똑같다.

## 믹스

```
악기 → out() → 세대 버스:  m 음악 · s 세상 · x 세상(sfx 레인을 거치지 않음) · 각각의 잔향 보냄 · e 메아리 보냄

  m → mus 레인 → 음악 줄기 ─┐
  s → sfx 레인 → 세상 줄기 ─┤
  x ──────────→ 세상 줄기 ─┤
  바람·돌풍·비 침대 ─────────┼→ mix → 고역통과 24 Hz → 컴프 → +0.8 dB → 리미터 → 부드러운 클립(-1.4 dBFS 상한) → master 레인 → 음소거 → 출력
  잔향 보냄 → 그릇 잔향(만든 3.2초 임펄스, ConvolverNode) → rev 레인 ─┤
  메아리 보냄 → 골짜기 메아리(1.2초, 170 Hz–1.5 kHz, 되먹임 0.28 = echoFb 레인) → echo 레인 ─┘ (그릇 잔향으로도 조금)
```

- 줄기(stem): `beds`(바람·돌풍·비), `mus`(배경 음악), `sfx`(세상의 소리). `offline(…, { only })`와 `listen.mjs --stem`이 하나만 남긴다.
- 탐색(seek)은 새 세대 버스를 만들고(50 ms에 걸쳐 켬) 옛 세대를 40 ms에 걸쳐 끈다. 클릭이 나지 않는다.
- 침대(바람, 돌풍, 비)는 세대에 속하지 않는다. 컨텍스트가 살아 있는 동안 계속 돌고, 탐색은 크기만 옮긴다.
- 금 간 종(57.0)과 죽은 딸깍은 `x` 버스로 간다. 57.0에 음악·세상 레벨이 15 ms 안에 0이 되어도 그 둘만은 들린다. 잔향·메아리는 0.1초 뒤에 끊긴다. 세상은 58.5, 메아리 59.5, 음악 60.05, 잔향 60.4에 돌아온다.
- 비 소리 세기: 방울마다 떨어지는 때부터 땅에 닿을 때까지 0.1초마다 귀(샷의 피사체)와의 거리를 재서 더한 곡선(10 Hz)이다. 귀에서 d m 떨어진 방울은 `exp(-(d/R)²)`만큼 센다(R은 샷마다 14–70 m). 땅에 닿는 소리와 놓이는 순간도 조금 더한다. 샷마다 다듬고(`RTRIM`), 컷에서는 0.5초 꼬리로 줄어든다. S17은 몇 시간 뒤라 0이다.
- 측정(`tools/listen.mjs`, 48 kHz 오프라인 렌더, 전체 93초, 비 모듈의 실제 방울): 통합 -16.5 LUFS, 순간 최대 -8.5 LUFS, 최고 -1.8 dBFS(57.0 금 가는 소리), 클릭 0, 울림 22개 모두 제 시각, `releaseMismatch` 0, 큐 954개(플링크 391). 초별 RMS: 가장 큰 곳(69–74 비와 합창) -13~-18 dBFS, 테마(81–87) -16~-17, 쉿(0–12) -27~-37, 마(60–66) -35~-42, 58.0–59.5 무음.

## 악기 (`INST[k](D, when, offset, a)`)

`when`은 소리가 시작하는 컨텍스트 시각, `offset`은 탐색 뒤 중간부터 들어갈 때 이미 지난 초(짧은 소리는 늦으면 건너뛴다). 공통 인자: `v` 크기, `pan` -1..1, `rev` `echo` 보냄, `bus` (`'m'` 음악, 기본은 세상), `seed` 잡음 조각.

| k | 레시피 | 주요 인자 `a` |
|---|---|---|
| `drum` | 사인, 60 ms에 음높이 2.2배 → 1배, 저역 잡음 터짐, 펠트 쿵, 가죽 모드. `ring`이면 배음 화음(D2의 2–5배음) | `n v soft ring pan rev echo` |
| `chime` | 자유 막대 배음 1, 2.756, 5.404, 8.933, 3.5초 감쇠(위 배음일수록 빨리) | `n v dec det pan` |
| `hbell` | 손종 1, 1.19, 1.5, 2.0, 2.66. `thin`이면 맥놀이 나는 두 번째 기음(0.25 % 위) | `n cents v dec thin` |
| `jingle` `crack` `tick` | 장난감 종 묶음 / 벌어진 배음 + 83 Hz 떨림 + 잡음 80 ms + 둔탁한 노크 / 죽은 딸깍 | `v` |
| `plink` | 1.6f → f 25 ms 사인, 120 ms 감쇠. 멀수록(`far` 0..1) 어둡고 젖음 | `n v far pan` |
| `plip` `splash` `glug` `gulp` | 물에 닿는 방울 / 물보라 / 물독 거품 / 개구리가 삼키는 소리 | `f v` |

## tools/listen.mjs

헤드리스 Chrome(또는 Edge)에서 페이지를 열고 `FILM.music.offline()`으로 소리를 렌더해서 16비트 WAV로 쓰고, 그 샘플을 Node에서 잰다. Node 22 이상이 필요하다(전역 `fetch`, `WebSocket`).
페이지는 기본이 `index.html`이고, 따로 빌드한 페이지도 된다.

```bash
python tools/build.py --out build/sound.html                                     # 들어 볼 페이지를 따로 빌드(안 하면 index.html)
node tools/listen.mjs --page build/sound.html                                    # 전체 → build/listen.wav, 초마다 RMS/최고값, LUFS
node tools/listen.mjs --page build/sound.html --spec build/s.png --spec-fscale log --spec-start 40 --spec-stop 14000   # 스펙트로그램(ffmpeg 필요)
node tools/listen.mjs --page build/sound.html --from 64 --dur 8 --kinds voice --fft 66.6,68.4 --clicks   # 목소리만, 포먼트, 클릭
node tools/listen.mjs --page build/sound.html --stem beds --bands                # 한 줄기 + 초마다 대역 균형
node tools/listen.mjs --page build/sound.html --expect 27,30,33,57,66,67.5,69,90.3   # 그 시각에 소리 시작이 있는가(ms 오차)
node tools/listen.mjs --page build/sound.html --live --wait 3000                 # 실제 컨텍스트: start, clock, seek, pause, mute
```

| 옵션 | 뜻 |
|---|---|
| `--page --out` | 렌더할 페이지(기본 `index.html`), WAV 경로(기본 `build/listen.wav`) |
| `--from --dur --sr` | 구간(필름 초), 샘플레이트(기본 48000. LUFS 필터 계수는 48 kHz용) |
| `--stem beds\|mus\|sfx` `--kinds a,b` | 한 줄기만 / 그 악기만 |
| `--clicks` | 샘플 불연속(2차 차분이 바로 앞 수준보다 크게 튐)과 가장 가까운 큐 |
| `--fft t1,t2` | 그 시각의 스펙트럼 봉우리와 대역 에너지 |
| `--bands` | 초마다 6대역(<80, 80–250, 250–800, 0.8–2.5k, 2.5–6k, 6k+) dB |
| `--expect t,..` `--onsets N` | 기대 시각마다 120 ms 안의 가장 강한 시작점(오차 ms, 세기, 대역. 없으면 `MISSING`), 가장 강한 시작점 N개 |
| `--spec png` `--spec-fscale` `--spec-start/stop` `--spec-drange` `--spec-size` | ffmpeg 스펙트로그램 |
| `--live` `--wait ms` | WAV 대신 실제 AudioContext로 start, 시계, seek(66, 56.5), pause, mute를 차례로 시험한다 |
| `--eval js` | 렌더 전에 실행(예: `FILM.music.lanes.rumble.forEach(p => p[1] = 0)`) |
| `--chrome` `--size` `--quiet` | 브라우저 경로, 창 크기, 초별 표 생략 |

## 예

```js
// 다른 모듈이 로드될 때(start() 전에) 소리 발신원을 넘긴다(같은 이름의 기본 묶음을 대신함)
FILM.music.add('chimewings', beats.map(b => ({ t: b.t, k: 'wing', a: { v: .03, pan: b.pan } })));

const [heavy, marble, mist] = FILM.music.rainAt(FILM.dev.T);
// 녹음: 69초부터 6초를 48 kHz로
const buf = await FILM.music.offline(48000, 69, 6);
```
