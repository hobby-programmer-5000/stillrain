# CAST — 펠, 톡, 던 (`film/cast.js`, `FILM.cast`)

세 인물을 빚고, 뼈대에 올리고, 얼굴을 셰이더로 그리고, 필름 시간마다 자세를 잡는다.
모든 자세는 `t`의 순수 함수다. 몸은 원화 시간(`FILM.anim.held`, 초당 12장)으로 움직이고, 망토·앞머리 한 가닥·후드 술·구슬 줄은 매 프레임 움직인다.
흔들림은 시뮬레이션이 아니라 경로 속도에서 바로 계산하므로(지난 프레임 기록 없음) 아무 시각으로 바로 건너뛰어도 같은 그림이 나온다.

만드는 방법과 각 함수의 설명은 `cast.js` 맨 위 머리말과 본문 주석에 있다.

## 만들어진 것

| 인물 | 몸 | 따로 붙는 것 |
|---|---|---|
| 펠 (후드 꼭대기까지 약 1.35 m, 후드 쓴 머리가 키의 약 1/4) | 조각 몸 1개(SkinnedMesh, 뼈 15개) | 머리(얼굴 셰이더), 후드(두께 있는 면 두 장: 둥근 껍데기 + 처마), 망토(매 프레임 CPU), 앞머리 한 가닥, 지팡이(갈고리, 약 1.97 m), 손종 + 이끼 벙어리장갑, 술 3개 + 유리구슬 7개(인스턴스), 57.0 이후 깨진 조각과 추 |
| 톡 (약 0.11 m) | 조각 몸 1개(놋쇠 종 목, 살구색 부리와 발, 검은 구슬 눈) | 날개 2장(인스턴스) |
| 던 (약 1.5 m) | 조각 몸 1개(SkinnedMesh, 뼈 15개, 통 같은 몸, 왼쪽 어깨 너머 회색 땋은 머리, 북끈) | 머리(실눈·주름 셰이더, 1.1배), 판초 숄(82.5에 펠에게 옮겨 감), 지름 0.9 m 북, 펠트 북채 |

`path.js`는 펠의 키로 바이블의 1.38 m(`PELL_H`)를 쓴다. 머리 중심(1.13 m)은 조각한 펠과 맞다.

잉크: 펠 `#3A1F33`, 후드 `#8A2A1A`, 톡 `#2B2E5C`, 던 `#3B2630`.
셀은 3단이다. `cel()`의 기본값(wrap −0.1, midAt 0.33)으로 N·L 약 0.43 위는 밝음, 0.10–0.43은 중간(그림자색 40%), 0.10 아래는 그림자다(바이블 §8은 0.45 / 0.10). 그림자는 채도를 14% 올린다.

## 호출

| 호출 | 하는 일 |
|---|---|
| `FILM.cast.update(t)` | 세 인물을 기본 안무대로 세운다 (main이 매 프레임 부름. 펠 → 톡 → 던 순서) |
| `FILM.cast.pellPose(t, opts)` | 펠의 자세. 기본은 `FILM.path.pell(t)`의 위치·방향·상태를 따른다. 자세 객체를 돌려준다 |
| `FILM.cast.tockPose(t, opts)` | 톡의 자세. 기본은 지팡이 갈고리 위. 그 순간의 계획(plan)을 돌려준다 |
| `FILM.cast.dunPose(t, opts)` | 던의 자세. 기본은 `FILM.path.dun(t)`를 따른다. 자세 객체를 돌려준다 |
| `FILM.cast.EXPR`, `FILM.cast.MOUTH` | 표정 키와 입 모양 키 |
| `FILM.cast.PAL` | 팔레트 (바이블 §3의 색) |
| `FILM.cast.steps(scene)` | main이 로딩 화면 뒤에서 돌리는 빌드 단계 두 개 |
| `FILM.cast.bench(n)` | (개발용) 조각 메시마다 만드는 시간(ms, n번 중 최소) |
| `FILM.cast.bootMs` | (개발용) 펠을 만드는 단계별 누적 시간 |

장면은 `update` 다음에 `pellPose(t, opts)`를 다시 불러 덮어쓰면 된다. 망토·술·앞머리는 그 프레임의 마지막 자세로, 그리기 직전에 한 번만 계산한다(`scene.onBeforeRender`에 이어 붙임).

## `pellPose(t, opts)` 옵션

| 옵션 | 값 | 뜻 |
|---|---|---|
| `expr` | 아래 표정 키 | 표정 |
| `mouth` | `closed` `o`(`small-o`) `hum` `ah` `oh` `laugh` `grin` `clench` | 입 모양 (표정의 입을 덮음) |
| `blink` | 0..1 또는 `false` | 눈꺼풀을 적어도 이만큼 감음 / 깜빡임 끄기 (기본은 3장짜리 자동 깜빡임, 평균 3.5초마다) |
| `gaze` | `[x, y]` -1..1 | 눈동자 (x+ 는 펠의 왼쪽, y+ 는 위) |
| `look` | `[x, y, z]` 월드 | 그 점을 본다 (목이 80%, 나머지는 눈. 목은 좌우 ±1.2, 위로 0.7, 아래로 0.6 rad까지) |
| `head` | `{ nod, turn, tilt }` 라디안 | 머리에 더함 (nod+ 는 숙임, turn+ 는 펠의 왼쪽) |
| `lean` | 라디안 | 몸을 앞으로 기울임 |
| `arms` | `{ L: [x,y,z], R: [x,y,z] }` | 손 목표, 캐릭터 공간(발 사이 원점, +z 앞, +x 왼쪽, m) |
| `staff` | `{ mode, dir, grip, base, face }` | 지팡이. mode: `R` `L`(한 손, grip은 밑동에서 손까지 길이 m), `both`(grip `[왼손, 오른손]`), `free`(base에 세움), `back`(등에 멤). dir은 지팡이 방향, face는 갈고리가 열리는 쪽 |
| `bell` | `{ mode, mitten, cracked }` | 손종. mode: `L` `R`(손에), `belt`(왼쪽 허리), `lap`(무릎) |
| `wet` | 0..1 | 젖음: 천이 20% 어두워지고 후드가 납작해짐 |
| `shawl` | 0..1 | 던의 숄이 펠에게 옮겨 오는 정도 |
| `squash` | 숫자 | 발을 축으로 눌림/늘어남, 부피 유지 (1 = 그대로, 0은 무시) |
| `smear` | `[x,y,z]` 월드, m | 스미어 프레임: 움직이는 방향 벡터. 그 반대쪽을 향한 정점을 이만큼 뒤로 끌어 늘임 |
| `onOnes` | `true` | 원화 시간 대신 매 프레임 (S08 도약, S13 낙하에서 씀) |
| `state` `pos` `yaw` | | 경로 대신 이 상태·위치·방향 (망토·술의 흔들림은 여전히 경로 속도를 따름) |
| `dots` | `true` | 점 눈 강제 (보통은 눈 폭이 화면에서 약 7–12 px 아래로 줄면 저절로) |

표정 키: `neutral` `eager` `sad`(`sidelined`) `determined`(`resolved` `reckless`) `strain` `stunned` `still`(`broken`, 깜빡임 없음) `wonder` `singing` `joyful`(`happy`) `peace`.
괄호 안은 바이블이 펠의 기분에 붙인 이름으로, 같은 표정을 가리킨다.

상태(경로가 주는 것): `roof` `run` `watch` `walk` `grip` `sprint` `leap` `crouch` `climb` `step` `hop` `bell` `still` `sing` `fall` `land` `sit` `stand` `bench`, 그리고 시험용 `idle`.

## `tockPose(t, opts)` / `dunPose(t, opts)`

| 옵션 | 값 | 뜻 |
|---|---|---|
| 톡 `mode` | `crook` `hood` `fly` `ground` `hop` | 앉을 곳 / 날기 / 땅 / 두 자리 사이 깡충 (`hop`은 plan에 `from` `to` `k`) |
| 톡 `puff` | 0..1 | 놀라 부풀기 (1 = 1.3배) |
| 톡 `trill` | `true` | 종 목을 활짝 열고 지저귐 |
| 톡 `turn` | 라디안 | 머리 돌림 (기본은 1.25초마다 바뀌는 해시 값) |
| 톡 `plan` | 객체 | 기본 계획 일부 덮어쓰기. `fly` `ground`의 `off: [x,y,z]`는 펠의 캐릭터 공간 오프셋(날 때는 목 높이 기준) |
| 톡 `onOnes` | `true` | 원화 시간 대신 매 프레임 |
| 던 `face` | `[눈 뜸, 웃음, 입 벌림, 눈썹 내림]` 0..1 | 얼굴 |
| 던 `look`, `arms`, `state`, `onOnes` | | 펠과 같음 (던의 `look`은 목만 돌림, 70%) |

## 예

```js
// S10: 결심한 얼굴로 종을 보고, 57.0 뒤에는 놀람
FILM.cast.pellPose(s.abs, { expr: s.abs < 57 ? 'determined' : 'stunned', gaze: [.25, -.6] });
// 카메라가 펠의 눈을 겨눔
const eye = FILM.cast.pell.eye.getWorldPosition(new THREE.Vector3());
// 톡을 어깨 옆에 띄워 지저귀게
FILM.cast.tockPose(t, { mode: 'fly', plan: { off: [.3, .45, .1] }, trill: true });
```

## 시험 보기

| 보기 | k |
|---|---|
| `pell` | 0–5: 18.5 지붕, 26.1 달리기, 42.6 질주, 55.55 종, 67.2 노래, 84.25 웃음 / 6–9: 정면, 3/4, 옆, 뒤 |
| `face` | 0–5: neutral, eager, sad, determined, singing, joyful (짝수 k는 정면, 홀수 k는 3/4, 0.74 m) |
| `tock` | 0 갈고리 위(30.2), 1 부풂(57.4), 2 날며 지저귐(69.2) |

`pell`(0–5), `tock`, `dun`은 표에 없는 k를 주면 `--at` 시각을 보여 준다. 시험 보기는 인물만 그 시각으로 세우고, 나머지 모듈은 `--at` 시각 그대로 둔다.

```bash
node tools/shot.mjs --test dun --k 0,1,2 --cols 3 --w 640 --out build/cast-dun.jpg
```

## 알아둘 것

- 던은 81–82.45에 펠의 북쪽 0.6 m로 걸어온다. 숄을 두르려면 닿아야 하고, S16 카메라에서 둘이 나란히(북은 옆으로) 보이게 하려고. 지금은 `FILM.path.dun`도 같은 자리에서 끝나므로, `dunPose`의 섞기는 도착을 부드럽게 하고 반쯤 왔을 때 펠 쪽으로 돌려세우는 일만 한다.
- 82.5–84에 펠은 던의 머리를 보는데, `update()`가 펠을 먼저 세우므로 직전 자세의 던 머리 위치를 쓴다.
- 펠 얼굴의 그림자는 그림자 맵을 받지 않고 셰이더가 그린다(앞머리 그림자, 턱 아래 목 그림자). 후드 처마 그림자가 눈을 덮지 않게.
- 조각 메시는 시작할 때 한 번 만든다. 후드와 숄은 조각이 아니라 두께 있는 면이라 거의 공짜다.
- 망토·술·구슬·앞머리의 흔들림은 경로(`FILM.path.pell`)의 속도로 계산한다. 장면이 `pos`로 위치를 바꿔도 흔들림은 경로를 따른다.
