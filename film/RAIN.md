# RAIN — 머문 비 (`film/rain.js`, `FILM.rain`)

소리를 기다리며 공중에 머문 비. 비 무리(필드), 물방울 줄, 마을의 물방울, 이야기 물방울, 영웅 물방울(유리), 소리의 고리를 그린다.
모든 물방울은 필름 시간 t의 순수 함수다. 놓이는 시각(release time)은 불러올 때 물방울마다 한 번 계산해 속성에 담는다.
공식과 톨 표는 `FILM.events.releaseTime`과 같다: `tr = t0 + 거리/30 + hold + 0.08·seed` (밴드가 맞고 reach 안일 때).
떠다니는 방울의 거리는 그 톨이 울린 순간 필드가 있던 자리에서 잰다. 착지 높이(`gnd`)도 불러올 때 한 번 어림한다.

움직임은 정점 셰이더(`RAIN_CORE`)가 계산하고, JS에는 같은 공식을 옮긴 거울(`hangJS`, `stateJS`)이 있어서
달팽이, 시험 화면 같은 다른 모듈이 GPU를 읽지 않고도 방울의 자리를 물을 수 있다.
코드 주석의 M3, M4, M6, M10, M11은 `film/BIBLE.md` 5장의 대표 동작 번호다.

## 구성

| 층 | 개수 | 크기 | 그리기 | 비고 |
|---|---|---|---|---|
| 굵은 방울 (HEAVY, 밴드 0) | 5,600 | r 0.09–0.22 m | 쿼드 3패스 | 아래층 0–14 m. 약 1/40은 올챙이, 넷 중 하나는 물왕관 |
| 물방울 줄 (strand) | 150줄 · 약 15,600알 | r 0.055–0.09 m(7알마다 1.3배), 0.5 m 간격 | 쿼드 + 가는 물실 | 60%는 계단 둘레의 구슬 커튼. 필드 안에서 땅 위 2.5 m까지 |
| 구슬 (MARBLE, 밴드 1) | 36,000 | r 1–3 cm (화면 최소 지름 1.6 px) | 쿼드 | 가운데층 12–26 m |
| 안개 (MIST, 밴드 2) | 92,000 | 점 1–3 px | `gl.POINTS` | 위층 24–38 m에 85%, 0–38 m 전체에 옅게 15% |
| 몸체 (body) | 210 | 반지름 5–14 m | 큰 스프라이트 | 멀리서 덩어리 실루엣. 가까우면 사라짐, 제 밴드가 떨어지면 옅어짐 |
| 마을 물방울 (local) | 약 120줄 + 낱알 470 + 안개 덩이 3 (약 3,200알) | | 쿼드 | 물독 길, 펠의 지붕, 9단, 벤치, S01 숲, 장난감 종 아이. 땅에 고정(펠의 종 둘레 안개만 필드를 따라감) |
| 영웅 물방울 (glass) | 16 | hops 10 + H + 이야기 5 | `E.glass`, 층 `E.GLASS` | 뒤 장면이 거꾸로 비친 축소판, 젤리 찌그러짐 |
| 소리의 고리 | 4쌍 + 반짝이 2 | 반지름 30·(t−t0) m | 가산 구면 | reach > 30 m인 톨(북, 풍경, 둥근 지붕 종, 목소리, 톡). 목소리(66.0, 67.5)는 ×4 |

그리기 호출은 최대 26개다(방울 세트 4개 × 3패스, 안개, 몸체, 영웅 물방울과 그 깊이 대역, 고리 8, 반짝이 2. 고리와 반짝이는 소리가 날 때만).

측정값(1080p, `tools/shot.mjs`로 비를 숨겼을 때와 비교, Windows의 ANGLE·D3D11): 프레임 0.9–2.5 ms(목표 5 ms),
불러오기 약 445 ms(필드 427 ms: 굵은 27, 줄 36, 구슬 136, 안개+몸체 227 / 목표 600 ms). 셰이더 컴파일은 비 쪽이 약 1.1 s를 더한다.
루프를 유니폼 횟수로 돌려 풀림(unroll)을 막았고, 놓임 시각과 착지 높이는 미리 계산한다. 불러오기 시간은 `FILM.rain.timing`(ms)으로 다시 잴 수 있다.

## 물방울의 생김새 (바이블 8장 "Drops")

- 안: 거꾸로 선 골짜기. 휜 수평선 위는 땅(그림자 톤이 맨 위), 아래는 하늘(아래로 갈수록 짙음). 올려다보면 하늘이 많고 내려다보면 땅이 많다.
- 테: 얇고 어두운 시안 선(#5FC8E0). 화면에서 약 1.2–2.9 px로 방울 크기와 상관없이 일정하고, 빛 반대쪽이 조금 두껍다.
- 빛: 해 쪽(왼쪽 위로 끌어당김)에 콩팥 모양 하이라이트, 반대쪽에 작은 점, 반대쪽 안쪽 테에 모인 빛.
- 몸은 72% 불투명(알파 투 커버리지)이라 뒤가 살짝 비친다. 하이라이트와 테는 불투명. 화면에서 반지름 2.4 px 아래인 방울은 은빛 점 하나로 그린다.
- 별 반짝임(네 갈래)은 held 시계로 깜빡인다: 소리가 살아 있으면(`uLive`) 초당 6번, 정적이면 3번 바뀐다(그림 2장, 4장 동안 유지). 역광일수록 잦다.
- 렌즈에 가까운 방울(`bokehNear` 안)은 부드러운 보케 원(최대 반지름 `maxPx` 90 px). 초점이 맞은 방울은 그 5배(450 px)까지 그대로 그린다.
- 떨림(M6): 머무는 음이 쌓이는 동안 방울이 떨며 은빛으로 하얘진다.
- 놓일 때: 0.2 s 흰 금빛(#FFF3C8) 섬광(방울이 40% 부푼다), 지나가는 다른 소리에는 약한 반짝임. 이어 떨어지며 카메라 기준 속도 방향으로 꼬리가 늘어난다(노출 `streak`, 최대 반지름 40배·320 px).
- 땅에 닿으면 사라지고, 굵은 방울·구슬·줄 구슬 넷 중 하나쯤은 0.25 s 물왕관(고리와 물살 여섯 갈래, 튀는 물방울)을 남긴다. 안개는 왕관이 없다.
- 줄 구슬은 위 구슬까지 가는 물실로 이어진다.
- 3패스: 0 작은 방울·꼬리·왕관(깊이 안 씀) → 1 화면 반지름이 `uLargePx`(10 px)보다 큰 방울(깊이를 써서 가까운 것이 먼 것을 덮고, 피사계 심도와 잉크 선이 잡힌다) → 2 보케(맨 위).
- 멀리서 1 px도 안 되는 구슬은 솎아 낸다(56 m까지 전부, 116 m 너머는 1/4만). 먼 필드가 반짝이 가루가 아니라 비로 읽히게 하려는 것이다.

## 움직임

| 바이블 | 구현 |
|---|---|
| M3 숨쉬기 | 방울마다 작은 흔들림(줄은 한 줄이 함께, 위상이 아래로 늦어짐), 필드 테두리의 느린 들숨날숨, 14 m 높이를 중심으로 늘었다 줄었다 |
| M3 떼 지어 기울기 | 해석적 컬 노이즈(텍스처 없음) × 2·(0.3 + gust), 돌풍 때 높이에 따른 전단(필드 가운데 19 m 위는 바람 쪽, 아래는 반대로, 최대 5 m) |
| M4 부채 자국 | `P.fans(t)` 18개, 수평 가우스(σ≈4 m, 20 m 안), 1.5 s(2박) 주기, 주로 위로 최대 3 m, `P.FANS_ON`(23.5–35 s) |
| M6 떨림 | 머무는 음이 닿은 뒤 1.5 s 동안 x²으로 커지는 떨림(14–20 Hz)과 흰빛. 시험 허밍(64.5)처럼 짧으면 떨기만 한다. 머무는 음은 모두 D라서 굵은 방울만 떤다 |
| M10 구슬 커튼 | 펠이 지나간 자리(지난 1.05 s의 위치 8개)를 감쇠 용수철(1.3 Hz, 감쇠비 0.32) 무게로 섞어 옆으로 밀어낸다. 줄 구슬은 100%, 낱 굵은 방울은 60% |
| 놓임 | `fallDist`(종단 속도 14/9/2.2 m/s, 중력 6 m/s²), 필드의 수평 흐름은 떨어지는 동안에도 이어진다 |

떨어진 방울의 출발점은 놓인 순간의 자리로 고정된다(흔들림, 돌풍, 바람 방향, 부채 위상 모두 그 시각에서 계산).
다만 셰이더는 부채와 펠의 위치를 이번 프레임의 유니폼으로 읽으므로, 그 둘 근처에서 떨어지는 방울은 JS 거울(`stateJS`)과 출발점이 조금 다를 수 있다.

## API

| 호출 | 반환 / 뜻 |
|---|---|
| `steps(scene)` | 불러오기 단계 4개: `비 무리를 띄우는 중`, `마을 물방울을 다는 중`, `큰 물방울을 빚는 중`, `소리의 고리를 거는 중` |
| `finalize(scene)` | 다른 모듈이 넘긴 구슬(`addBeads`)을 한 세트로 만든다. 그 뒤의 `addBeads`는 세트를 바로 다시 만든다 |
| `update(t)` | 매 프레임(장면의 update보다 먼저). 부채·펠·필드 속도 유니폼을 채우고, 옵션을 기본값으로 되돌리고, 땅 색을 시간에 맞추고, 영웅 물방울과 고리를 움직인다 |
| `set(o)` | 이번 프레임의 모양 옵션(아래 표). 장면의 update에서 매 프레임 부른다 |
| `reset()` | 옵션을 기본값으로(땅 색은 그대로, 다음 `update`가 맞춘다) |
| `shock(t, cam)` | 카메라를 지나는 목소리 고리: `[[cx, cy, 반지름(화면 높이 단위), 세기], ...]` 최대 2개 → `look.shock`. cx, cy는 화면 0–1 |
| `addBeads(list)` | 구슬 추가. `{ p:[x,y,z] 월드, ts 나타남, tr 놓임(빼면 ts 뒤의 소리로 계산), band 0\|1\|2, size 반지름 m, seed, until }`. 기본값 band 2, size 8 cm/2 cm/6 mm(밴드별), seed는 위치에서. 땅에 고정된 낱알 |
| `strands` | 줄 목록 `{ kind 'field'\|'local', drifting, top, set, first, n, seed, place }` |
| `strandAt(i, t)` | 줄의 구슬들(위부터) `{ p, r, tr, state 0 매달림\|1 떨어짐\|2 닿음, on }` |
| `strandPts(i, t)` | 매달려 있는 구슬 위치만 `[[x,y,z], ...]` (위부터. 달팽이, 하늘덩굴용) |
| `strandsNear(p, t, r = 20)` | 줄 꼭대기까지의 수평 거리가 r m 안인 줄 `[{ i, d }]` (가까운 순) |
| `beadAt(i, j, t)` | 줄 i의 j번째 구슬(필드 줄은 j=0이 맨 위, 마을 줄은 j=0이 끝방울). 필드 줄의 잘린 구슬은 r 0, on false |
| `hero(id, t)` | 영웅 물방울 상태 `{ pos, sx, sy, a2, a3, trem, show }`. id: `hop0`–`hop9`, `heart`, `macro`, `frog`, `nose`, `face`, `palm` |
| `HERO` | 영웅 물방울 정의 목록 `{ id, kind, local, r, tr, drifting, ... }` (hops와 heart는 `ts`, 이야기 물방울은 `since`, `until`, `tad`, `land`가 더 있다) |
| `releases(t0, t1, c, r = 30, max = 60, bands)` | 그 사이 c 근처에서 놓이는 방울 `[{ t, p, band, r, d }]` (가까운 순 max개를 시간순으로). 모든 방울을 훑으므로 가끔만 쓴다 |
| `fallingNear(t, c, r = 40)` | 지금 떨어지는 방울 수(놓인 지 3.5 s 안, 놓인 자리에서 수평 거리). 세 알에 하나만 보고 3을 곱한다 |
| `sets` | 원자료. `big` `marble` `local` `beads`: `rest`(3) `info`(band, r, seed, flags) `life`(since, until, tr, hang) `aux`(떨림 도착, 끝, 줄 seed, 실 길이) `gnd`. `mist`: `rest` `info`(tr, r, seed, flags) `gnd`. `body`: `a`(x, y, z, 반지름) `b`(seed, band, tr, 0) |
| `counts()` | 세트별 개수 `{ big, marble, mist, body, local, beads }` |
| `relTime(x,y,z,drift,band,seed,since)` | 놓임 시각(JS, `FILM.events.releaseTime`과 같은 값, 1e9 = 놓이지 않음) |
| `hangJS`, `stateJS`, `groundStep`, `curl` | 셰이더와 같은 공식의 JS 거울 |
| `GLSL`, `DRAW2D` | 다른 모듈이 쓸 수 있는 셰이더 조각(`RAIN_CORE`, 방울 얼굴용 2D 도형) |
| `COL`, `FLAGS {DRIFT, BEAD, TAD, SPLASH}`, `timing`, `checkBad` | 색, 플래그 비트(1, 2, 4, 8), 불러오기 시간(ms), 놓임 시각 자가 점검(다른 값 개수, 0이어야 함) |

### `set(o)` 옵션 (한 프레임만 유효)

| 키 | 기본 | 뜻 |
|---|---|---|
| `bokehNear` | 1.6 m | 이보다 가까운 매달린 방울은 보케 원(0.4배 거리에서 완전히) |
| `streak` | 0.075 s | 꼬리 노출 시간(길이 = 카메라 기준 속도 × 이 값) |
| `minPx`, `maxPx` | 0.8, 90 | 방울 화면 반지름 최소, 보케 최대(초점 맞은 방울은 그 5배까지) |
| `body` | 0.2 | 몸체 불투명도. `haze`도 같은 뜻으로 받는다(둘 다 주면 `haze`가 이김) |
| `ground`, `groundShade` | 시간에 따라 | 방울 안 땅 색(밝은 면, 그림자). 75.5–80 s에 비취색, 86.5–87.5 s에 노을을 비춘 물빛으로 |
| `camVel` | [0,0,0] | 카메라 속도(m/s). 꼬리를 카메라 기준으로 그린다(S13에서 필수) |
| `invert` | 0.3 | 유리 물방울이 거꾸로 담는 범위(화면 높이 단위). S01 접사는 0.5 |

## 예

```js
// S13: 카메라가 펠과 함께 떨어진다 → 가까운 비는 멈춘 듯, 먼 고리는 처진다
const p1 = P.pell(s.abs + .01).pos, p0 = P.pell(s.abs - .01).pos;
FILM.rain.set({ camVel: [(p1[0] - p0[0]) / .02, (p1[1] - p0[1]) / .02, (p1[2] - p0[2]) / .02] });

// S12: 목소리 고리의 굴절
look.shock = FILM.rain.shock(s.abs, s.cam);

// S01: 접사 물방울 안의 골짜기를 넓게
FILM.rain.set({ invert: .5, bokehNear: .3 });

// 생물 모듈: 날갯짓 한 번에 물보라 한 알(실제로는 12알씩)
FILM.rain.addBeads(beats.map(b => ({ p: b.pos, ts: b.t - .02, tr: b.t + .01, until: b.t + 6.5, band: 2, size: .004 })));
```

## 시험 화면 (`node tools/shot.mjs --test <이름> --k 0,1,2,3 --out build/rain.jpg`)

시험 화면마다 k별로 자기 시각을 정해 비의 시계만 그 시각으로 맞춘다(세상의 나머지는 `--at` 시각에 머문다).

| 이름 | k | 무엇 |
|---|---|---|
| `field` | 0–5 | 골짜기 위 넓게: 10 s(멀리 낮은 곳에서), 28.5 s(북의 장막), 31 s(풍경), 40 s(돌풍), 26.1 s(부채 아래에서 올려다봄), 35.5 s(안개 장막) |
| `drops` | 0–3 | 굵은 방울 1–3 m(10 s), 필드 줄(10 s), S01 접사 방울(0.6 s), 장난감 종 아이의 안개(14.2 s) |
| `drop` | 0–3 | 굵은 방울 하나를 0.55, 1.1, 2.2 m에서 조금 위로부터, k=3은 0.9 m 아래에서 하늘을 배경으로(`--at`, 없으면 10 s) |
| `release` | 0–3 | 9단에서 올려다본 북의 고리: 27.3, 27.8(섬광 목걸이), 28.6(떨어지는 장막), 30.5(풍경의 고리) |
| `hops` | 0–3 | 47, 49, 51, 53 s 펠 둘레의 징검다리 물방울과 구슬 커튼 |
| `fall` | 0–2 | 69.3, 70.2, 71.5 s 펠과 함께 떨어지는 카메라 |
| `story` | 0–3 | 개구리 방울(15.5), 코 방울(21.9), 얼굴 방울 떨림(64.95), 손바닥 방울(90.32) |
| `voice` | 0–3 | 66.25, 66.9, 67.85, 68.6 s 목소리 고리와 반짝이 |

## 다른 모듈과의 약속

- `rain.update(t)`는 장면의 update보다 먼저 돈다. 그래서 장면이 부른 `set()`이 그 프레임의 기본값을 이긴다.
- 영웅 물방울은 깊이만 쓰는 대역(`rain-hero-depth`, renderOrder 999)을 불투명 장면에 함께 그린다. 그래서 피사계 심도와 잉크 선이 물방울을 안다.
  대역은 1.5% 작아서 유리 껍질이 늘 그 앞에 있고, 유리 패스의 깊이 검사에 지워지지 않는다.
- `shock(t, cam)`의 cam은 이번 프레임에 자리를 잡은 카메라여야 한다. 시험 화면 `voice`는 그래서 같은 카메라를 따로 만들어 넘긴다.
- 소리의 고리는 필드 층(밑면에서 약 35 m 위까지)을 지나는 부분이 반짝인다. 아래에서 보면 놓이는 고리가 띠로 보인다.
- 필드 줄은 땅 위 2.5 m에서 끝난다(계단식 땅 `groundStep` 기준). 떨어진 방울은 미리 계산한 착지 높이(`gnd`)에서 사라진다.
- `music/synth.js`는 `sets`를 읽어 놓이는 소리와 빗소리 크기를 맞춘다. 배열의 배치를 바꾸면 그쪽도 함께 바꿔야 한다.
