# LIFE — 골짜기의 작은 생명 (`film/life.js`, `film/crowd.js`)

모든 장면이 사람 사는 곳처럼 보이게 하는 작은 것들이다. 식물과 생물은 `life.js`(`FILM.life`), 마을 사람과 쉿 천은 `crowd.js`(`FILM.crowd`)가 맡는다.
모두 필름 시간의 순수 함수다. 생물·식물·사람은 원화 시간(`uHeld`, 초당 12장, 2프레임 간격)으로 움직이고, 술·천·떨어지는 것은 매 프레임 움직인다.
샷이 따로 옮길 필요 없이 `update(t)`가 알아서 자리와 동작을 정한다.

식물은 자리만 JS에서 한 번 정하고(모듈마다 이름 붙은 난수열이라 열 때마다 같다), 움직임은 모두 버텍스 셰이더에서 계산한다. 생물과 사람은 원화 한 장마다 JS에서 자세를 계산해 인스턴스 행렬과 인스턴스 속성에 쓴다.
시각은 영화 전체와 같은 식에서 온다. 소리 표(`FILM.events`의 울림 표, 방출 시각, 낙하 곡선)와 `events.wetAt`의 녹색 홍수 규칙이다. 단위는 미터와 초다(개구리만 센티미터로 빚는다).

## FILM.life

| 호출 | 설명 |
|---|---|
| `steps(scene)` | 로더 단계 셋: `잎과 갈대를 심는 중`, `개구리를 빚는 중`, `새와 나방을 풀어 놓는 중` |
| `finalize(scene)` | 비 가닥이 생긴 뒤 덩굴과 달팽이를 만든다. 비 모듈이 없으면 등록된 방울을 여기서 점으로 그린다 |
| `update(t, dt, cam)` | 개구리·새·나방은 원화 한 장마다, 올챙이·달팽이·대역 방울은 매 프레임 |
| `beads(list)` | 안개 방울 등록. `FILM.rain.addBeads`가 있으면 그쪽으로, 없으면 `life.js`가 그린다. 항목 `{ p:[x,y,z], band:2, size, seed, ts(생기는 때), tr(떨어지는 때), until(사라지는 때) }` |
| `frogs` | `[{ pos, yaw, s, seed, hero?, chorus? }]`. 0번이 주인공 |
| `frogPose(i, t)` | `{ pitch(올려다봄), sq(납작 1=보통), jaw(입 벌림 rad), sac(목주머니 반지름 cm), blink, lx(항상 0), ly, hop, turn }` |
| `FROG_TR`, `FROG_LAND` | 개구리 방울이 떨어지는 때(≈15.76), 입에 닿는 때(≈16.04). `FILM.events`와 같은 식 |
| `bird(i, t)` | 새 i의 위치 `[x,y,z]`, 보이지 않으면 `null`. 0–39 무리 A, 40–79 무리 B |
| `birdRing(i, t)` | 그 새가 지금 날갯짓으로 방울을 떨어뜨리는 중인지 |
| `NB` | 새 수(80) |
| `FLOCK_A` | 무리 A의 세 구간 `{ t0, t1, ring:[울리는 시작, 끝], pts, scatter? }` |
| `wetTime(x, z)` | 그 땅이 젖는 때(`FILM.events.wetAt`이 0.5를 넘는 때의 닫힌 식) |
| `beds`, `leaves`, `plops`, `moths`, `snails` | 배치 목록 |
| `counts()` | 개수 확인 |
| `meshes` | 만든 메시들(디버그용) |

## FILM.crowd

| 호출 | 설명 |
|---|---|
| `steps(scene)` | `마을 사람들을 모으는 중`: 인형 하나를 InstancedMesh 81개(80명 + 대역)로, 쉿 천, 웃음·발구르기 계획, 웃음 이슬비 방울 등록 |
| `update(t)` | 자세는 원화 한 장마다, 술 계측(M17)과 천은 매 프레임(천은 운반하는 57–70.5만 원화 시간) |
| `pose(i, t)` | 사람 i의 자세 `{ pos, yaw, s, aL, aR, lean, roll, hp, hy, bob, sq, pa, pb, pc, gait, gAmp, prop, hide }` |
| `people` | `{ role, group, kid, prop(0 없음, 1 부채, 2 박 장대, 3 장난감 종), robe, hood, felt, scale, seed, ... }` |
| `N` | 인스턴스 수(81) |
| `laughs` | `[{ i, t0, dur, head, kid }]` 81–87 웃음(신스와 웃음 이슬비) |
| `stomps` | `[{ t, pos, i }]` 아이들의 물웅덩이 발구르기(물보라, 소리) |
| `cloth(t)` | 쉿 천 상태 `{ c, R, dip, sag, billow, dir, dx, dz, lowered, vis }` |
| `head(i, t)` | 머리 위치(방출점용) |
| `mesh`, `clothMesh` | 만든 메시(디버그용) |
| `standIn` | `true`면 cast.js가 없을 때 감빛 두건 펠 대역을 그린다(시험 화면용) |

마을 사람의 하루: 12–18 물독 길(인사: 손가락을 입술에, 그다음 편 손바닥 / 방울 줍는 이 / 13.5 장난감 종 아이와 쉿 하는 아이), 14–21 부채꾼 오르막, 24–33 부채질(`P.fans(t).phase`), 25 위를 봄, 33 다 같이 숨을 내쉼(어깨가 3장에 걸쳐 내려감), 36–38 돌풍에 비틀거리고 부채가 꼬임, 39 모든 두건이 동쪽 스필웨이로(한 장씩 엇갈림), 57–70 천 운반(60부터 달림), 69–76 손바닥을 펴고 비를 맞음, 72부터 29명이 천으로 달려옴, 73 받기, 75 내려놓기, 81–87 웃음·발구르기, 87 귀가. 듣는 이는 4–6초마다 자세 하나, 8장에 걸쳐 바뀜.
웃음 이슬비(M13): 웃음마다 머리 2.2 m 위에 74.5부터 걸린 안개 방울 40개가 웃는 동안 하나씩 떨어진다.

## 시험 화면

빌드한 `index.html`을 찍는다(`python tools/build.py`). 다른 빌드를 찍으려면 `--page`로 지정한다.

```bash
node tools/shot.mjs --test leaves --k 0,1,2 --cols 3 --w 640 --out build/life-leaves.jpg      # 26.5 쉼, 28.5 북을 향함, 77 물 찬 컵 + 새싹 + 덩굴
node tools/shot.mjs --test frog --k 0,1,2,3 --cols 2 --w 800 --out build/life-frog.jpg      # 14.0, 15.2 부풂, 16.15 받기, 16.4 흐뭇
node tools/shot.mjs --test birds --k 0,1 --cols 2 --w 800 --out build/life-birds.jpg        # 9.5 가로지름, 37 돌풍에 흩어짐
node tools/shot.mjs --test small --k 0,1,2,3 --cols 2 --w 800 --out build/life-small.jpg    # 20.4 나방, 착지 1장 전 입 벌림, 77.3 새싹, 14.5 달팽이
node tools/shot.mjs --test tadpoles --k 0,1 --cols 2 --w 800 --out build/life-tadpoles.jpg  # 33.62, 77.1
node tools/shot.mjs --test crowd --k 0,1,2,3 --cols 2 --w 800 --out build/life-crowd.jpg    # 13.58, 27.3, 39.4, 84.2
node tools/shot.mjs --test cloth --k 0,1,2 --cols 3 --w 640 --out build/life-cloth.jpg      # 72.9, 73.15, 73.5
```

## 원칙과 바꾼 점

- 외곽선(뒤집은 껍데기)은 개구리·마을 사람·천·달팽이에만. 잎·갈대·새싹·덩굴은 칠한 테두리만.
- 수는 프레임 예산 안에 들도록 바이블보다 줄였다: 컵잎 약 5.9천(바이블 8천), 방울갈대 약 2.6천(3천), 새싹 약 4.2천(6천).
- 식물이 느끼는 돌풍은 `lfGust`다. 36에 일어 39.5–44에 잦아들고, 그 뒤 0.1 세기의 바람이 52–60에 사라진다. 돌풍 앞면은 서쪽 테두리에서 초속 18 m로 동쪽으로 건너간다(world.js와 같은 M16). `P.gust`의 44초 뒤 0.35 바람을 그대로 쓰면 잎이 계속 뒤집혀 있다.
- 새는 멀어도 1080p에서 날개 폭 18 px 아래로 작아지지 않게 버텍스 셰이더에서 키운다. 무리 A의 길은 S02, S07, S16 카메라에 들어오게 잡았다.
- 주인공 개구리는 1.3배(약 16 cm), 합창 개구리는 1.2–1.4배. 나방은 날개 폭 약 12 cm.
- 옷 계측(M17)의 술 떨림은 `0.85·e^(−6.5τ)·sin(2π·11τ)`로, 바이블의 `0.25·e^(−8τ)`보다 크고 길게 흔든다.
- 물독 물 높이는 `pos.y − 0.05 + size × (1.36 → 1.5, 넘침 2.5초 전부터)`로 잡았다(world.js의 넘침 순서와 같음).
- 물방울 안의 올챙이(S01)는 rain.js가 그린다. 여기 올챙이는 물독에 떨어지는 것들이다.
