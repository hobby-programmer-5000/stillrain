# WORLD — 홀로미어 골짜기와 하늘 (`film/world.js`, `FILM.world`)

걷지도 노래하지도 떨어지지도 않는 모든 것: 땅, 계단식 밭과 돌담, 연못, 마을, 종 기둥, 물독, 산, 하늘, 구름, 시간대별 빛.
모든 것은 필름 시간 `t`의 순수 함수다. `update(t)`는 유니폼만 쓰고(그리고 아래 세계 지도를 다시 그린다), 움직임은 셰이더 안에 있다.
단위는 미터, 초, 라디안이고 x가 동쪽, z가 남쪽, y가 위다.

## 어떻게 동작하나

- **조명**: 시간대마다 해·하늘·안개·구름 색을 모두 담은 "키"가 있고, `FILM.anim.keys()`가 필름 시간으로 섞는다.
- **세계 지도**: 구름 그림자와 종소리가 남긴 젖음은 목록을 도는 계산이라, 매 프레임 한 번 작은 텍스처(분지 중심 2000 m 사방, 768 × 768, R 구름 그림자, G 젖음)에 그려 둔다. 재질은 그 텍스처를 한 번 읽기만 한다.
- **지형**: 극좌표 메시 640열. 모든 열이 같은 표본 목록(연못 12점, 테라스마다 담 7점과 윗면 9점, 테두리 24점, 산맥마다 16점, 먼 가장자리 2점)을 가져서 3.2 m 담 단차가 열끼리 어긋나지 않는다. 칠은 셰이더 둘이 나눠 한다(분지, 테두리 밖).
- **마을**: 집·지붕·소품을 메시 몇 개로 합치고 셀 셰이더 하나(`E.toon`)로 칠한다. 정점마다 부품 번호(`aPart`)와 자유 vec4(`aX`: 회전축과 시각)가 있어서 문 커튼, 종, 청동 막대, 물독 물이 셰이더 안에서 움직인다.

## 로더 단계

| 단계 이름 | 하는 일 |
|---|---|
| 골짜기 땅을 다지는 중 | 구름 그림자/젖음 지도, 산 능선 텍스처, 지형 메시(극좌표, 640열) |
| 하늘을 칠하는 중 | 하늘 돔, 적운, 연못 |
| 마을을 세우는 중 | 집(기둥·벽·문 커튼·쿠폴라 소매·종), 지붕 |
| 종 기둥과 물독을 세우는 중 | 종 기둥·청동 막대·사다리 못, 배수로, 듣는이 벤치, 물독, 깃발 |

## 공개 API

| 이름 | 종류 | 설명 |
|---|---|---|
| `sunOverride` | `null` 또는 `{dir:[x,y,z], col?:'#hex', k?:number}` | 장면이 해를 바꿀 때. `update`와 카메라 뒤 `afterCamera`에서 적용(같은 프레임에 반영). 끝나면 `null`로 돌려놓는다. `col`을 줄 때는 `k`도 함께 준다(`afterCamera`는 `k`가 없으면 세기 1을 쓴다) |
| `fieldShadeK` | `null` 또는 0..1 | 빗방울 무리가 땅에 드리우는 얼룩빛 세기. `null`이면 시간대로(0.42, 69–72 s에 사라짐) |
| `light(t)` | 함수 | 그 시각의 조명 키(해 방향·색, 하늘 색, 안개, 구름 색 …, 선형 RGB) |
| `groundAt(x, z)` | 함수 | 그려지는 땅 높이. 분지와 테두리 40 m까지는 `FILM.valley.ground`와 같고, 90 m 밖은 산맥(그 사이는 섞임) |
| `cloudShadow(x, z, t)` | 함수 | 움직이는 구름 그림자 0..1 (GLSL `cloudShadow`와 같은 식, 현재 해 방향 사용) |
| `wetAt(x, z, t)` | 함수 | `FILM.events.wetAt` 그대로 (M12 젖음) |
| `gustDelay(x)` | 함수 | M16 지연: `max(0, (x − 서쪽 테두리 x) / 18)` 초 (서쪽 테두리 x ≈ −182 m) |
| `snap(x, t)` | 함수 | 그 x에서 돌풍이 천을 때리는 충격(감쇠 진동 2.1 Hz, 36 s + 지연부터) |
| `blow(x, t)` | 함수 | 그 x의 지연된 돌풍 세기 `FILM.path.gust(t − 지연)` |
| `CLOUD_GLSL` | GLSL | `float cloudShadow(vec2 xz, float t)` (유니폼 `uCSa uCSb uCSk uNCS`는 `FILM.U`에 있다) |
| `MAP_GLSL` | GLSL | 싼 조회: `vec4 worldMap(xz)`(r 구름 그림자, g 종소리 젖음), `cloudShadowAt(xz)`, `halftone(k)`(45° 망점, 1080p에서 5 px) |
| `clouds` | 배열 | 구름 목록 `{kind:'drift'\|'gust'\|'tower', x0, z0, base, R, rz, H, vx, vz, seed, k}` (위치 = x0 + vx t, k = 그림자 세기) |
| `meshes` | 객체 | `terrain dome clouds pond house roof props streamers`, `cupHouses`(33 s에 울리는 집 4채), `cisterns` |
| `bootMs` | 객체 | 땅 단계 안의 시간 `{skyline, terrain}` (ms, 디버그) |
| `steps(scene)` | 함수 | 로더 단계 목록 `[[이름, 할 일], …]` (main.js가 불러 차례로 실행) |
| `update(t)` | 함수 | 매 프레임, 장면보다 먼저: 조명 키와 순간 스위치를 유니폼에 쓰고 세계 지도를 그린다 |
| `afterCamera(t)` | 함수 | 장면이 카메라를 놓은 뒤: `sunOverride`를 다시 적용하고 그림자 빛과 세계 지도를 맞춘다 |

다른 모듈이 구름 그림자를 받으려면 셰이더 pars에 `FILM.world.MAP_GLSL`을 넣고 `lightK *= 1.0 - 0.8 * cloudShadowAt(vWP.xz);` 하면 된다(텍스처 한 번 조회).

## 시간대 조명 (`light(t)`)

| 시각 (s) | 키 | 느낌 |
|---|---|---|
| 0 – 36 | noon | 높은 남서쪽 해(고도 약 51°), 코발트 천정 `#2F6FD6` · 중간 `#5DB2F0` · 지평 `#CFE7F2` |
| 36 → 37.2 – 42 | gust | 36–37.2 s에 천천히 바뀐다. 슬레이트 청록 하늘 `#4C6B7A`, 흐림 0.85, 질주하는 구름 그림자 |
| 42 – 60 | run | 맑은 낮, 해가 조금 서쪽 |
| 60 – 66 | ma | 엷고 고요함 |
| 66 – 72 | climax | 낮은 해(고도 약 22°, 역광), 크림색 은테 구름, 따뜻한 지평 |
| 72 – 75 | curtain | 비의 장막, 회청색, 흐림 0.5 |
| 75 – 87 | after0 → after | 비 갠 뒤 짙은 하늘, 84.6–86 s에 해가 다시 세진다 |
| 87 – 93 | dusk | 복숭아 `#F2B48A` → 라일락 `#B39AD6`, 해 고도 4°, 물 찬 밭이 하늘을 비춤 |

그 밖의 경계(42, 60, 66, 72, 75, 87 s)는 컷이라 0.02 s 안에 바뀐다. `FILM.U.uShade`(그림자 색)는 main.js가 장면마다 등급표(`FILM.score.GRADE`)로 정하므로 `update`는 건드리지 않는다.

## 장소와 시각 (앵커)

| 무엇 | 어디 / 언제 |
|---|---|
| 지붕 | 집마다 `HOUSE.roof` 타원체의 위 절반 그대로 → `FILM.valley.roofY`가 정확 |
| 스필웨이 기둥 | `FILM.valley.places.spillway.mast`, 발판 윗면 = 기둥 y + 12, 못 24개(0.7 m부터 0.45 m 간격) |
| 듣는이 벤치 | 앉는 면 = `bench` y + 0.45 |
| 듣는이 오두막 | `places.spillway.hut` (집 모델, 크기 0.8) |
| 쿠폴라 종 | `meshes.cupHouses` 4채: 소매 30.5 s에 벗김, 종 33.0 + 0.09 i 에 흔들림. 고르는 규칙은 `FILM.valley.cupolas`(종소리의 소리 원점)와 같아야 한다 |
| 차임 기둥 막대 | 30.0 + 0.05 k 에 흔들림 |
| 문 커튼·소매 (M16) | 36 s + `gustDelay(집 x)`에 튕김. s07 안(36–42)에는 서쪽 집들(x < 약 −74 m)까지만 닿는다 |
| 녹색 홍수 (M12) | 밭 k가 75.5 + 0.5 (9 − k)에 바깥 가장자리부터 비취색, 앞쪽에 0.6 m 물때 띠, 연못 80 s |
| 담을 넘는 물줄기 | 담 k(밭 k+1 아래)에서 76.2 + 0.5 (9 − (k+1)) 부터, 2.5–5 s 뒤에 사라짐 |
| 배수로 물 | 75.8 s부터 |
| 물독 넘침 | 물독 거리 7개: 76.6 + 0.35 i, 집 옆 물독: 76.2 + 0.5 (9 − k) + 0.4..0.8 |
| 돌풍 구름 그림자 | x = −6010 + 150 t (지름 약 500 m), 36–42 s에 분지를 서→동으로 지난다 |

## 땅 메모

- 담의 실제 위치: 테라스 경계 `R(k) = 40 + 16.5k + w(.5 + k/9)`와 판정 경계 `B(k) = 40 + .5w + 16.5k` 중 큰 쪽.
  `B > R`이면 `FILM.valley.ground`는 `B`에서 3.2 m 수직으로 뛴다. 메시는 모든 열에서 같은 순서(담 7점, 밭 윗면 9점)로 표본을 잡고,
  단차 바로 양쪽(±0.015 m)에 점을 둬서 이웃 열의 담 아래와 담 위가 잘못 이어지지 않는다.
- 테두리 첫 점은 R9 + 0.02다. R9에 딱 맞추면 부동소수 오차로 점이 안팎으로 갈려 톱니가 생긴다.
- 산맥 세 겹(테두리 너머 거리 D, 반폭 W, 높이는 절대 높이): 가까운 산 D 235 · 봉우리 98–140 m · 숲, 가운데 D 880 · 235–305 m · 푸름, 먼 산 D 2350 · 660–920 m · 눈.
  동쪽 ±0.5 rad는 열려 있고(훗랜즈 평원 −50 m), 테두리에서 2.7 km쯤 밖에 낮은 메사 줄이 있다.

## 테스트 뷰

먼저 `python tools/build.py`로 `index.html`을 만든다(`shot.mjs`가 기본으로 찍는 페이지).

```bash
node tools/shot.mjs --test valley --k 0,1,2,3,4,5 --cols 2 --w 800 --at 8 --out build/world-valley.jpg
node tools/shot.mjs --test village --k 0,1,2,3 --cols 2 --w 800 --at 8 --out build/world-village.jpg
node tools/shot.mjs --test sky --k 0,1,2 --cols 2 --w 800 --at 8 --out build/world-sky.jpg
```

| 뷰 | k | 무엇 |
|---|---|---|
| `valley` | 0 | 남쪽 테두리에서 연못 너머 마을 |
| | 1 | 서쪽 밭(중심에서 125 m)에서 스필웨이 노치 쪽(동) |
| | 2 | 종 울림 밭(9번 밭, 북동)에서 남서로 |
| | 3 | 스필웨이 어깨에서 골짜기 쪽(s14 · s17 방향) |
| | 4 | 밭 위 높은 크레인 |
| | 5 | 노치 너머 훗랜즈 |
| `village` | 0 | 집 가까이 |
| | 1 | 펠의 지붕 |
| | 2 | 듣는이 오두막, 벤치, 스필웨이 기둥 |
| | 3 | 물독 거리 |
| `sky` | 0 | 연못 남쪽 낮은 밭에서 올려다본 적운 |
| | 1 | 남쪽 테두리에서 먼 산 위 탑 구름 |
| | 2 | 스필웨이에서 해 쪽(역광) |

`--at`으로 시각을 고른다: 8 낮, 31 첫 비 뒤, 37–41 돌풍, 77 녹색 홍수, 89 해질녘.

## 예시

```js
// 장면에서: 역광으로 해를 돌려놓고, 장면이 끝나면 되돌린다
F.world.sunOverride = { dir: [-.8, .4, .45] };   // 다음 장면 update에서: F.world.sunOverride = null;

// 다른 모듈의 천 조각을 M16 연쇄에 맞추기
const k = F.world.snap(x, t) * .7 + F.world.blow(x, t) * .4;

// 셰이더에서 구름 그림자 받기
E.toon({ fpars: F.world.MAP_GLSL, fpre: 'lightK *= 1.0 - 0.8 * cloudShadowAt(vWP.xz);' });
```

## 비용

RTX 2070 Max-Q, 1080p에서 잰 값이다. 다른 작업이 GPU를 함께 쓰던 때라 범위로 적었다.

- 부팅(이 모듈의 로더 단계): 땅 0.48–0.86 s(그중 메시 약 0.45 s, 능선 텍스처 약 0.1 s), 마을 0.02–0.07 s, 기둥·물독 0.13–0.35 s. 합계 0.65–1.3 s(부하에 따라).
- 프레임: 같은 넓은 화면에서 `film/stub.js`의 임시 골짜기보다 2.5–3.8 ms 더. 그중 지형이 약 2.8 ms(칠하기) + 0.6 ms(기하).
- 셰이더 컴파일(main.js의 '셰이더를 굽는 중' 단계): 임시 골짜기보다 2–3 s 더(부하가 크면 더). 가장 큰 것은 분지 지형 셰이더(약 1–2 s).
- 셰이더 프로그램: 지형 2(분지, 테두리 밖 — 하나로 합치면 둘을 따로 하는 것보다 컴파일이 1.5배쯤 느리다), 마을 1 + 잉크 1(집·지붕·천·기둥·물독이 모두 한 셰이더),
  깃발 1, 하늘 1, 구름 1, 연못 1, 세계 지도(구름 그림자·젖음) 1. ANGLE(D3D11)은 첫 그리기에서 컴파일하므로 미리 `compile`해도 숨겨지지 않는다.
